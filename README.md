# Siam University Vehicle Rental

A Python object-oriented programming project for a simple campus vehicle-rental desk.

## Files

- `rental.py` — `Vehicle`, `Renter`, `ElectricCar`, and `Motorbike` classes
- `main.py` — demonstration program

## How to run

Open a terminal in this folder and run:

```bash
python main.py
```

## Features

- Rent and return vehicles
- Validate renter name and licence number with `@property`
- Use inheritance for `ElectricCar` and `Motorbike`
- Demonstrate polymorphism by printing mixed vehicle types in one loop
